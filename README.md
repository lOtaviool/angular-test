# Angular Test

Este projeto consiste em um teste realizado com o framework Angular da empresa SCCON Geospatial.

---

# Objetivo

Demonstrar conceitos e habilidades em uma arquitetura front-end moderna utilizando Angular.

---

# Tecnologias

## Frontend

- Angular
- TypeScript
- HTML
- SCSS

## Bibliotecas

- Angular Material
- RXJS
- NG-Mask

## Comunicação de rotas

- ViaCEP
- IndexedDB

## Testes

- Jasmine
- Karma

---

# Instalação

## Clone o projeto

```bash
git clone https://github.com/SEU USUARIO/angular-test.git
```

---

# Instalar dependências

## Aplicação

```bash
cd angular-test

npm install
```

---

# Execução

## Server

```bash
ng serve
```

```txt
http://localhost:4200
```

---

# Testes

## Executar testes

```bash
ng test
```
